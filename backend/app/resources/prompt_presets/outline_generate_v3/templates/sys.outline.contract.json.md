你必须只输出一个 JSON 对象。标签外禁止任何文字，不要 Markdown 代码块围栏，不要解释说明。

- 主要人物的成长/变化路径（标注每人的"谎言"与"真相"，即内心的错误信念与需要学会的东西）

- 节奏规划（高潮、低谷、呼吸点的章节分布）
- 信息释放计划（关键真相在哪些章节以什么方式被揭露）
- 不要写成正文，写成可执行的策划文档

chapters 数组要求：
- number 从 1 递增，不得跳号或重复
