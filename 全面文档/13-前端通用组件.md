## 1 布局系统（`components/layout/`）

### 1.1 AppShell（主应用框架）

**文件**：`AppShell.tsx`

#### 整体结构

AppShell 是全站唯一的顶层布局容器，采用 `flex` 双列布局：

- **左侧边栏**（`<aside>`）：桌面端固定宽度 260px（可收起到 56px），移动端隐藏并以抽屉覆盖。
- **右侧主区域**（`<main>`）：包含顶部 `<header>` 和带 `PersistentOutlet` 的内容区。

#### 侧边栏状态持久化

通过三个自定义 Hook 将用户偏好写入 `localStorage`（按 userId 隔离 key）：

| Hook | Storage Key 工厂 | 功能 |
|------|------------------|------|
| `useSidebarCollapsed` | `sidebarCollapsedStorageKey(userId)` | 侧边栏折叠/展开 |
| `useAdvancedDebugVisible` | `advancedDebugVisibleStorageKey(userId)` | 高级调试导航是否显示 |
| `useAdvancedDebugCollapsed` | `advancedDebugCollapsedStorageKey(userId)` | 高级调试区是否折叠（默认折叠） |

#### 内部子组件

| 子组件 | 说明 |
|--------|------|
| `SidebarLink` | NavLink 封装，配合 `framer-motion` 的 `layoutId` 实现激活态滑块动画 |
| `SidebarButton` | 普通按钮（如帮助），同 SidebarLink 样式 |
| `ProjectNavGroupTitle` | 导航分组标题，折叠时隐藏 |
| `renderProjectNavItems` | 根据导航组渲染链接列表 |

#### PersistentOutlet（路由缓存）

- 白名单匹配 `/projects/:id/writing`，命中的页面以 LRU 策略缓存最多 3 个实例。
- 非白名单页面不缓存，直接渲染当前 outlet。
- 缓存项通过 `display: none / block` 切换可见性，避免卸载/重新挂载。
- 使用 `PersistentOutletProvider` 注入 `outletKey` 和 `activeKey`。

#### 内容区容器

| 导出组件 | max-width | 用途 |
|----------|-----------|------|
| `PaperContent` | `max-w-4xl` | 阅读/编辑型页面 |
| `ToolContent` | `max-w-screen-xl` | 工具/管理型页面 |

两者均使用 `fadeUpVariants` 做进入/退出动画，并尊重 `prefers-reduced-motion`。

#### Header

- 动态标题来自 `resolveRouteMeta(pathname).title`。
- 显示当前用户名称、会话过期时间。
- 登录/登出按钮。
- 移动端汉堡菜单按钮。

#### 帮助抽屉

通过 `Drawer` 组件从右侧滑入，展示 `UI_COPY.help` 中的术语表和使用提示。

### 1.3 ProjectProviderGuard（项目上下文守卫）

**文件**：`ProjectProviderGuard.tsx`

### 2.4 Overlay（层叠管理核心）

**文件**：`Overlay.tsx`

所有 Modal/Drawer 的底层遮罩组件。

#### ESC 栈机制

通过全局 `window.__ainovelOverlayEscStack` 数组实现多层叠加的 ESC 关闭：

1. 仅挂载一次全局 `keydown` 监听器（`_ensureEscListener`）。
2. 每个打开的 Overlay 将自己的 close handler 压入栈顶。
3. 按 ESC 时只关闭栈顶的 Overlay。
4. Overlay 关闭时从栈中移除。

#### 遮罩交互

- `onPointerDown` 只在点击遮罩本身（`e.target === e.currentTarget`）时触发 `onBackdropClick`。
- 点击面板内部的事件不会冒泡到遮罩。

### 2.6 Toast 全局通知系统

### 5.2 AnnotatedText（`AnnotatedText.tsx`）

将章节正文与记忆标注叠加渲染。

#### 渲染流程

1. 调用 `buildAnnotatedTextSegments` 生成分段列表。
2. 纯文本段渲染为 `<span>`。
3. 标注段渲染为可点击的 `<button>`，底部带彩色边框：
   - hook: accent 色
   - foreshadow: info 色
   - plot_point: success 色
   - character_state: warning 色
4. 鼠标悬停显示 tooltip（包含类型、标题、重要度、内容摘要）。
5. 支持 `scrollToAnnotationId` 自动滚动到指定标注。

---

### 5.3 annotatedTextSegments.ts（分段算法）

#### 核心函数 `buildAnnotatedTextSegments`

输入：正文文本 + 标注数组 + 邻近容差（默认 5 字符）。

算法：
1. 将每个标注转为 `[start, end)` 区间。
2. 使用 `buildGroups` 按邻近容差合并重叠/临近区间。
3. 对每个组使用扫描线算法（start/end 事件排序），生成精确的子分段。
4. 每个子分段记录当前活跃的标注集合和组内所有标注。
5. `pickPrimary` 按重要度选出主标注。

输出类型：
```typescript
type AnnotatedTextSegment =
  | { kind: "text"; text: string }
  | { kind: "annotated"; text: string; start; end; groupAnnotations; activeAnnotations; primary };
```

测试覆盖：非重叠分段、邻近容差合并、重叠区间内的活跃标注追踪。

### 5.4 MemorySidebar（`MemorySidebar.tsx`）

章节记忆管理侧边栏，功能密集：

#### 主要功能

1. **类型过滤**：按类型显示/隐藏标注，每个类型旁显示计数。
2. **分组列表**：按类型 -> 重要度排序展示所有记忆条目。
3. **选中详情**：显示选中条目的类型、重要度、定位状态、完成状态。
4. **CRUD 操作**：
   - **新增/编辑**：右侧 Drawer 表单，含类型下拉、标题、内容、标签、重要度、position/length。
   - **删除**：带确认对话框。
   - **标记完成/取消完成**：调用 `markStoryMemoryDone` API。
   - **合并**：右侧 Drawer 多选源条目，调用 `mergeStoryMemories` API。

#### 使用的 API

| API | 功能 |
|-----|------|
| `createStoryMemory` | 新增 |
| `updateStoryMemory` | 更新 |
| `deleteStoryMemory` | 删除 |
| `markStoryMemoryDone` | 标记完成 |
| `mergeStoryMemories` | 合并多条到目标 |
