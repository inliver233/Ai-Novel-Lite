# 功能去除文档 (Phase 1) — 模块级精简指导纲领

> **本文档是给实施者的操作指南。** 目标：删除冗余功能模块，保留核心创作流程，确保系统在删除后仍可正常编译运行。
>
> **原则**：只删不改。不重构保留功能的内部实现，只切断被删功能的入口、路由、文件和引用。

## 二、推荐执行顺序

按依赖关系排序，**从低风险到高风险**，每步完成后验证编译通过：

```
Step 1: 术语/帮助 (Glossary)           → 独立，无依赖，最安全
Step 2: 章节阅读器 → 合并到预览         → 独立，低风险
Step 3: 高级调试框架 + 任务中心          → UI 层面
Step 4: 分形记忆 (Fractal)              → 记忆系统边缘模块
Step 5: 图谱/关系 (Graph)               → 依赖结构化记忆模型，但图谱服务独立
Step 6: 数值表格 (NumericTables)         → 有生成上下文注入
Step 7: 向量 RAG 页面                   → 页面删除，后端能力可保留
Step 8: 伏笔 (Foreshadows)              → 同时涉及 StoryMemory 和 StructuredMemory
Step 9: 结构化记忆 (StructuredMemory)    → 最高风险，影响面最广
Step 10: 世界书 (WorldBook)              → 最高风险，深度集成在生成流程
```

> **每完成一步，执行 `npm run build`（前端）和 `python -c "from app.main import app"`（后端）验证无报错。**
