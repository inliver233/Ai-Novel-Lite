# 14 - 前端写作模块组件

本文档覆盖 AI 小说写作平台前端写作页面的全部组件，包括 AI 生成抽屉、批量生成、章节分析、章节列表与虚拟滚动、内容优化对比、上下文预览、伏笔管理、生成历史、记忆更新、提示词检查器、表格面板、写作工具栏，以及所有子模块和工具函数。

---

## 2 类型定义（`types.ts`）

### 2.1 GenerateForm

章节生成的完整参数模型：

```typescript
type GenerateForm = {
  instruction: string;          // 用户指令
  target_word_count: number | null; // 目标字数
  macro_seed?: string;          // 宏种子（用于复现）
  prompt_override?: PromptOverride | null; // 提示词覆盖
  stream: boolean;              // 流式生成
  plan_first: boolean;          // 先生成规划
  post_edit: boolean;           // 润色
  post_edit_sanitize: boolean;  // 去味/一致性修复
  content_optimize: boolean;    // 正文优化
  style_id: string | null;      // 风格 ID
  memory_injection_enabled: boolean; // 记忆注入总开关
  memory_query_text: string;    // 记忆查询关键词
  memory_modules: {             // 9 个记忆模块开关
    worldbook: boolean;
    story_memory: boolean;
    semantic_history: boolean;
    foreshadow_open_loops: boolean;
    structured: boolean;
    tables: boolean;
    vector_rag: boolean;
    graph: boolean;
    fractal: boolean;
  };
  context: {                    // 上下文注入配置
    include_world_setting: boolean;
    include_style_guide: boolean;
    include_constraints: boolean;
    include_outline: boolean;
    include_smart_context: boolean;
    require_sequential: boolean;
    character_ids: string[];
    previous_chapter: "none" | "summary" | "content" | "tail";
  };
};
```

## 4 BatchGenerationModal（批量生成模态框）

**文件**：`BatchGenerationModal.tsx`

### 4.1 三步骤 UI

| 步骤 | 内容 |
|------|------|
| Step 1: Range | 从当前活跃章节之后开始顺序生成 |
| Step 2: Options | 数量（1~200）、是否包含已有内容的章节 |
| Step 3: Run | 启动/暂停/恢复/重试失败/跳过失败/取消 |

### 4.2 运行时状态

- **Runtime SSE 状态**：`idle / connecting / open / error`（来自 ProjectTaskRuntime）。
- **进度条**：`(completed + failed + skipped) / total * 100`。
- **Recovery point**：显示最新 checkpoint 的 status/completed_count/failed_count/skipped_count。
- **Runtime timeline**：按时序展示 SSE 事件。
- **Batch items**：每项显示章号、状态、尝试次数、request_id、错误信息。成功项可"Apply to editor"。

### 4.3 辅助函数

| 函数 | 功能 |
|------|------|
| `tryExtractRequestId` | 从 JSON/文本中提取 request_id |
| `tryParseJsonObject` | 安全解析 JSON |
| `buildStepLabel` | 生成每项的状态标签 |
| `formatProjectTaskStreamStatus` | SSE 状态人类可读文本 |

## 6 章节列表面板和虚拟列表

### 6.1 ChapterListPanel

**文件**：`ChapterListPanel.tsx`

薄封装层，将 `ChapterVirtualList` 包裹在一个固定高度的面板容器中（`h-[calc(100vh-220px)]`，最小 480px）。

### 6.2 ChapterVirtualList

**文件**：`ChapterVirtualList.tsx`

#### Props

| 属性 | 类型 | 说明 |
|------|------|------|
| `chapters` | ChapterListItem[] | 章节数组 |
| `activeId` | string \| null | 当前选中章节 |
| `onSelectChapter` | function | 选中回调 |
| `variant` | `"panel" \| "card"` | 渲染风格 |
| `getStatusLabel` | function | 自定义状态文本 |

#### 虚拟滚动实现

- 使用 `ResizeObserver` 测量视口高度。
- 通过 `getChapterVirtualWindow` 计算可见区间。
- `absolute` 定位 + `top: index * rowHeight` 实现虚拟定位。
- 每行固定 48px 高度。
- 选中章节变化时自动滚动到可见区域（`getChapterScrollTopForIndex`）。

### 6.3 chapterVirtualWindow.ts（虚拟窗口算法）

```typescript
function getChapterVirtualWindow(args): {
  startIndex: number;  // 渲染起始索引（含 overscan）
  endIndex: number;    // 渲染结束索引
  totalHeight: number; // 总高度 = itemCount * itemHeight
  offsetTop: number;   // 起始偏移
}
```

- 默认 overscan = 6 行。
- 空列表返回全零。
- 超出范围自动 clamp。

```typescript
function getChapterScrollTopForIndex(args): number | null
```
- 如果目标项在视口内返回 `null`（不滚动）。
- 目标在上方：返回 `itemTop`。
- 目标在下方：返回 `itemBottom - viewportHeight`。

测试覆盖：180 项的窗口计算、小列表 clamp、空列表、可见项不滚动、上下方滚动。

## 8 ContextPreviewDrawer（上下文预览抽屉）

**文件**：`ContextPreviewDrawer.tsx`

大型调试工具抽屉，功能包括：

### 8.1 记忆上下文包加载

调用 `/api/chapters/:id/memory_context_pack` API，传入当前生成参数（instruction、memory_query_text、memory_modules、budgets 等），返回 `MemoryContextPack`。

### 8.2 各 Section 展示

对 9 个 memory section 逐一渲染：

- 显示 `enabled` / `disabled`（disabled 时显示原因）。
- 显示 `text_md`（注入到提示词的文本）。
- 显示 budget 和 token 估计值。

### 8.3 上下文优化器（Context Optimizer）

解析 `render_log.context_optimizer`，展示每个 block 的优化前后 token/char 数，以及节省的 token 估计。支持 baseline vs optimized 对比视图。

### 8.4 预览 Bundle 下载

支持下载和复制完整预览 bundle JSON。

### 8.5 子模块

#### WorldbookPreviewPanel（`contextPreview/WorldbookPreviewPanel.tsx`）

- 显示触发的条目数量和预览。
- 显示 budget_char_limit、budget_source、token_estimate。
- 可展开查看触发条目列表（id/title/reason/match_source/match_value/priority）。
- 可展开查看注入文本和原始 pack JSON。

#### VectorRagDebugPanel（`contextPreview/VectorRagDebugPanel.tsx`）

Vector RAG 调试面板：

- query_text 输入框 + sources 复选框（worldbook/outline/chapter）。
- 查询 / 复制结果 JSON / 导出 JSON 按钮。
- 结果展示：
  - counts 统计（candidates_total/returned/unique_sources/final_selected/dropped_total）。
  - timings_ms 计时。
  - rerank 摘要（enabled/applied/method/top_k/timing_ms/changed_positions）。
  - hybrid 混合检索状态。
  - 注入预览（prompt_block.text_md）。
  - query preprocess（raw vs normalized + preprocess_obs）。
  - final.chunks 按 source/chapter 分组展示。
  - candidates 前 10 条预览。
  - 原始 JSON 折叠区。

#### useVectorRagQuery（`contextPreview/useVectorRagQuery.ts`）

管理 Vector RAG 查询的全部状态：

- `vectorQueryText` / `vectorSources`：查询参数。
- `runVectorQuery`：调用 `/api/projects/:id/vector/query`。
- `groupedVectorFinalChunks`：将 final chunks 按 source -> chapter -> chunk_index 三级分组排序。
- 打开/切换项目时自动重置状态。

#### vectorRag.ts（类型定义与归一化）

核心类型：
- `VectorCandidate`：候选 chunk（id/distance/text/metadata）。
- `VectorRagCounts`：统计计数。
- `VectorRerankObs`：重排序观测值。
- `VectorHybridObs`：混合检索观测值。
- `VectorRagQueryResult`：完整查询结果。

`normalizeVectorResult(raw)` 对后端返回的原始数据做严格的类型校验与归一化，确保前端类型安全。

辅助格式化函数：`formatRerankSummary`、`formatHybridCounts`、`formatOverfilter`。

#### utils.ts

两个工具函数：
- `writeClipboardText`：封装 `copyText`，失败时抛错。
- `downloadJson`：创建 Blob + 临时链接下载 JSON 文件。

## 12 MemoryUpdateDrawer（记忆更新抽屉）

| appliedChoice | `"raw" \| "post_edit"` | `"raw" \| "content_optimize"` |

同样使用 `buildNaiveUnifiedLineDiff` 生成行级差异。三视图切换：差异/原稿/后处理稿。

## 15 TablesPanel（表格面板）

### 15.1 双模式导出

| 组件 | 使用场景 |
|------|----------|

### 15.2 表格管理

- **加载表格列表**：`/api/projects/:id/tables?include_schema=true`。
- **创建表格**：默认 Key/Value schema。
- **重命名/删除表格**。
- **自动更新开关**：`auto_update_enabled`（章节定稿后自动排队更新）。

### 15.3 行编辑

- 加载行数据：`/api/projects/:id/tables/:tableId/rows?limit=200`。
- 渲染为 HTML `<table>`，根据列类型渲染不同输入控件：
  - `boolean` -> checkbox
  - `md` / `json` -> textarea
  - 其他 -> input
- 保存时按列类型做类型转换和必填校验。
- 支持新增行（自动生成默认值）和删除行（带确认）。

### 15.4 Schema 处理

- `normalizeColumns`：安全解析 schema.columns 数组。
- `isKeyValueSchema`：判断是否为双列 Key/Value 模式。
- `toCreateRowDefaults`：按列类型生成默认值。
- `parseJsonMaybe`：安全解析 JSON 类型字段。
