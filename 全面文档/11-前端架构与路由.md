### 3.3 路由守卫

1. **AuthGuard** (`components/layout/AuthGuard`)：验证用户认证状态，未认证重定向到 `/login?next=...`
2. **ProjectProviderGuard** (`components/layout/ProjectProviderGuard`)：从 URL 参数 `:projectId` 加载项目上下文，确保项目数据可用

### 3.4 错误边界

- 每一层路由都配置了 `errorElement: <RouteErrorPage />`
- RouteErrorPage 能区分 chunk 加载错误（前端版本更新导致）和常规错误，给出不同提示

## 4. 懒加载与代码分割策略

### 4.1 懒加载模式

所有 28 个页面组件都使用 `React.lazy()` + `importWithChunkRetry()` 实现懒加载：

```tsx
const LoginPage = lazy(async () => {
  const mod = await importWithChunkRetry(() => import("./pages/LoginPage"));
  return { default: mod.LoginPage };
});
```

采用命名导出转默认导出的模式（`{ default: mod.XXX }`），确保 named export 与 `React.lazy` 兼容。

### 4.2 Chunk 加载重试机制（lazyImportRetry.ts）

文件路径：`frontend/src/lib/lazyImportRetry.ts`

核心函数 `importWithChunkRetry` 实现了分包加载失败的自动恢复：

1. **错误检测** (`isChunkLoadError`)：检测以下错误特征：
   - "failed to fetch dynamically imported module"
   - "importing a module script failed"
   - "chunkloaderror"
   - "loading chunk ... failed"

2. **单次重试策略**：
   - 使用 `sessionStorage` 记录重载标记（key: `ainovel:chunk-reload-mark`）
   - TTL 为 60 秒，同一页面 60 秒内不重复刷新
   - 不同页面之间可分别重试
   - 重载时在 URL 添加 `_chunk_reload` 参数来刷新资源缓存

3. **防止无限重载**：每个 URL 在 60 秒窗口内只尝试一次自动重载

## 5. 路由工具库（routes.ts）

文件路径：`frontend/src/lib/routes.ts`

### 5.1 路由元数据

定义了 `resolveRouteMeta(pathname)` 函数，根据 URL 路径后缀匹配路由标题和布局类型：

```typescript
type RouteLayout = "home" | "paper" | "tool";
```

- **home**: 首页布局
- **paper**: 内容阅读类布局（设置、角色、大纲、预览、导出）
- **tool**: 工具类布局（写作、世界书、RAG、图谱等大多数页面）

包含 25 条路由元数据，通过 `pathname.endsWith(suffix)` 匹配。

### 5.2 测试

文件路径：`frontend/src/lib/routes.test.ts`

使用 Vitest 测试 `resolveRouteMeta` 的路径解析和 fallback 行为。

## 6. 全局类型定义（types.ts）

文件路径：`frontend/src/types.ts`

定义了系统核心的 TypeScript 接口：

### 6.1 LLM 相关

- `LLMProvider`: 支持的 LLM 提供商（openai / openai_responses / openai_compatible / openai_responses_compatible / anthropic / gemini）
- `LLMPreset`: 项目级 LLM 配置（provider、model、temperature、top_p、max_tokens 等）
- `LLMProfile`: 用户级 LLM 配置档案（含 API Key 信息）
- `LLMTaskCatalogItem`: 任务目录项
- `LLMTaskPreset`: 任务级 LLM 预设
- `LLMModelItem` / `LLMModelsResponse`: 模型列表

### 6.2 项目相关

- `Project`: 项目基础信息（id、name、genre、logline、active_outline_id、llm_profile_id）
- `ProjectSettings`: 项目设置（世界观、风格、约束、自动更新开关、向量 Rerank 配置、Embedding 配置、查询预处理配置）
- `QueryPreprocessingConfig`: 查询预处理配置（enabled、tags、exclusion_rules、index_ref_enhance）
- `ProjectSummaryItem`: 项目摘要（用于 Dashboard 卡片）

### 6.3 章节相关

- `ChapterStatus`: "planned" | "drafting" | "done"
- `ChapterBase`: 章节基础字段（id、project_id、outline_id、number、title、status）
- `ChapterDetail`: 扩展字段（plan、content_md、summary）
- `ChapterListItem`: 列表优化字段（has_plan、has_summary、has_content）
- `ChapterMetaPage`: 分页数据（chapters、next_cursor、has_more、total）
- `CreateChapterInput` / `UpdateChapterInput` / `BulkCreateChapterInput`

### 6.4 其他实体

- `Character`: 角色（name、role、profile、notes）
- `Outline` / `OutlineListItem`: 大纲
- `PromptPreset` / `PromptBlock` / `PromptPreview` / `PromptPreviewBlock`: 提示词系统

## 7. 全局样式系统

### 7.1 CSS 变量与主题（index.css）

文件路径：`frontend/src/index.css`

采用 CSS 自定义属性实现主题化：

**语义色彩变量**（使用 RGB 三元组格式以支持 Tailwind 透明度）：
- `--color-canvas`: 画布背景色
- `--color-surface`: 卡片/面板背景色
- `--color-surface-hover`: 悬停态背景
- `--color-ink`: 主文字色
- `--color-accent`: 强调色
- `--color-border`: 边框色
- `--color-subtext`: 次要文字色
- `--color-success` / `--color-warning` / `--color-danger` / `--color-info`: 语义色

**主题定义**：
- `[data-theme="paper-ink"]`: 浅色主题（纸质墨水感）
- `[data-theme="paper-ink"].dark`: 暗色变体

**字体系统**：
- `--font-ui`: Inter / Geist Sans / system-ui（界面字体）
- `--font-content`: Merriweather / Source Serif 4（正文衬线字体）
- `--font-mono`: JetBrains Mono / Fira Code（代码字体）

**动效变量**：
- `--motion-ease-standard`: cubic-bezier(0.25, 0.1, 0.25, 1)
- `--motion-duration-fast/base/slow`: 150ms / 250ms / 350ms
- `--motion-scale-press`: 0.98（按压缩放）
- 支持 `prefers-reduced-motion`，减少动效

**组件类（@layer components）**：
- `.btn` / `.btn-primary` / `.btn-secondary` / `.btn-ghost` / `.btn-danger` / `.btn-icon`: 按钮系列
- `.input` / `.textarea` / `.input-underline` / `.textarea-underline` / `.input-minimal`: 输入系列
- `.select` / `.checkbox`: 表单控件
- `.panel` / `.panel-interactive`: 面板/可交互面板
- `.surface` / `.surface-interactive`: 表面层
- `.skeleton`: 骨架屏
- `.state-card` / `.error-card` / `.state-title` / `.state-desc`: 状态卡片
- `.callout-warning` / `.callout-danger` / `.callout-info`: 提示条
- `.ui-focus-ring` / `.ui-transition` / `.ui-pressable`: 通用工具类

### 7.2 Tailwind 配置（tailwind.config.js）

文件路径：`frontend/tailwind.config.js`

扫描范围：`index.html` + `src/**/*.{ts,tsx}`

自定义扩展：
- **颜色**：11 个语义色（canvas、surface、surface-hover、ink、subtext、accent、success、warning、danger、info、border），全部基于 CSS 变量并支持 alpha-value
- **字体族**：ui / content / mono
- **圆角**：`rounded-atelier`（基于 `--radius-base`，默认 12px）
- **过渡**：`ease-atelier` / `duration-atelier-fast` / `duration-atelier` / `duration-atelier-slow`

### 7.3 主题初始化（index.html）

文件路径：`frontend/index.html`

内联脚本在 `<head>` 中立即执行，从 `localStorage` 读取主题偏好并应用到 `<html>` 元素：
- key 格式：`ainovel::theme::${userId}`
- 存储 `themeId` 和 `mode`（light/dark）
- 在 React 加载前就完成主题设置，避免闪烁
