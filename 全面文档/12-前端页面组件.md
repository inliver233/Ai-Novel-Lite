# 12 - 前端页面组件

## 1. 认证页面

### 1.1 LoginPage

- **文件路径**：`frontend/src/pages/LoginPage.tsx`
- **功能**：用户登录入口，支持用户名/密码登录和 LinuxDo OIDC 第三方登录
- **UI 布局**：全屏居中卡片布局（`min-h-screen` + `flex items-center`）
- **状态管理**：`useAuth()`（认证上下文）、`useToast()`（通知）、`useNavigate()`
- **API 调用**：
  - `auth.login({ userId, password })` -- 用户名密码登录
  - `fetchAuthProviders()` -- 查询可用的第三方登录提供商
  - LinuxDo OIDC: 重定向到 `/api/auth/oidc/linuxdo/start`
- **交互逻辑**：
  - 已登录自动重定向到 `next` 参数指定的路径
  - 支持 `?next=` URL 参数做登录后跳转
  - 处理 OIDC 回调错误（`?oidc_error=`）
  - dev_fallback 模式下显示"跳过登录"按钮
  - `safeNextPath` 函数防范开放重定向漏洞

### 1.2 RegisterPage

- **文件路径**：`frontend/src/pages/RegisterPage.tsx`
- **功能**：新用户注册，支持密码确认和 LinuxDo 登录
- **UI 布局**：与 LoginPage 相同的全屏居中卡片
- **状态管理**：`useAuth()`、`useToast()`
- **API 调用**：`auth.register({ userId, password })`
- **交互逻辑**：
  - 密码确认校验（`passwordMismatch`）
  - 注册成功后自动导航到 `next` 路径
  - 底部提供"已有账号"链接到登录页

## 2. 首页与项目管理

### 2.1 DashboardPage

- **文件路径**：`frontend/src/pages/DashboardPage.tsx`
- **功能**：项目总览仪表盘，展示所有项目卡片、创建新项目、推荐流程

## 10. 页面间导航关系

```
LoginPage / RegisterPage
    │（认证后）
    ▼
DashboardPage ─────────────────────────────────────────────────────
    │                                                               │
    ├─→ ProjectWizardPage（开工向导）                                │
    │       │                                                       │
    │       ├─→ SettingsPage（设置）                                 │
    │       ├─→ CharactersPage（角色）                               │
    │       ├─→ PromptsPage（模型配置）                             │
    │       ├─→ OutlinePage（大纲）                                  │
    │       ├─→ WritingPage（写作）                                  │
    │       ├─→ PreviewPage（预览）                                  │
    │       └─→ ExportPage（导出）                                   │
    │                                                               │
    └─→ 直接进入项目页面                                             │
        │                                                           │
        ├── WritingPage ←→ ChapterAnalysisPage                     │
        │       │                                                   │
        │       ├─→ ChapterReaderPage                              │
        │       └─→ TaskCenterPage                                 │
        │                                                           │
        ├── PromptsPage ←→ PromptStudioPage ←→ PromptTemplatesPage│
        │                                                           │
        ├── RagPage ←→ ImportPage                                  │
        │                                                           │
        ├── GraphPage ←→ StructuredMemoryPage                     │
        │                                                           │
        ├── WorldBookPage                                          │
        ├── FractalPage                                            │
        ├── ForeshadowsPage                                        │
        ├── NumericTablesPage ←→ TaskCenterPage                   │
        ├── SearchPage（搜索结果可跳转到各页面）                    │
        ├── StylesPage                                             │
        └── ExportPage                                             │
                                                                    │
AdminUsersPage（管理员入口，独立于项目）                            │
                                                                    │
NotFoundPage / RouteErrorPage（错误兜底）────────────────────────────
```

**核心导航特征**：

1. **向导驱动**：ProjectWizardPage 作为项目初始化的引导中心，按步骤串联 7 个页面
2. **写作为核心**：WritingPage 是创作主入口，可跳转到分析、阅读、任务中心
3. **提示词三级**：PromptsPage（配置入口）-> PromptStudioPage（高级）-> PromptTemplatesPage（新手）
4. **RAG 双入口**：RagPage（向量管理）+ ImportPage（数据导入），互相链接
5. **记忆系统联动**：GraphPage/StructuredMemoryPage/ForeshadowsPage/ChapterAnalysisPage 共享底层记忆数据
6. **搜索跳转**：SearchPage 的结果可跳转到几乎所有数据页面
7. **WizardNextBar**：多个页面底部都嵌入此组件，保持向导进度可见并引导下一步
