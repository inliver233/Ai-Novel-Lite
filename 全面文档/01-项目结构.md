## 2. 各目录功能说明

### 2.1 根目录

| 目录/文件 | 功能 |
|-----------|------|
| `backend/` | 后端 Python/FastAPI 应用 |
| `frontend/` | 前端 React/TypeScript 应用 |
| `docs/` | 项目技术文档（部署、设计、安全、测试等） |
| `scripts/` | 项目级别工具脚本（仓库 Guard 等） |
| `test/` | 端到端测试、合同测试、性能测试 |
| `issues/` | Issue 追踪记录 |
| `plan/` | 开发计划与迭代文档 |
| `.codex/` | Codex AI 代理配置与技能模块 |

### 2.2 后端目录 (`backend/`)

| 目录 | 功能 |
|------|------|
| `app/` | 应用主代码 |
| `app/api/` | HTTP API 层：路由注册与请求处理 |
| `app/api/routes/` | 各功能模块的 API 路由实现 |
| `app/core/` | 基础设施：配置、认证、加密、日志、错误定义 |
| `app/db/` | 数据库层：会话管理、迁移、工具 |
| `app/llm/` | LLM 适配层：统一客户端、多 Provider 实现 |
| `app/llm/providers/` | 各 LLM Provider 的具体实现 |
| `app/models/` | SQLAlchemy ORM 数据模型 |
| `app/resources/` | 静态资源（内置 Prompt 预设模板） |
| `app/schemas/` | Pydantic 请求/响应数据模型 |
| `app/services/` | 业务逻辑服务层（核心代码所在） |
| `app/services/mcp/` | MCP (Model Context Protocol) 服务 |
| `app/utils/` | 通用工具函数 |
| `alembic/` | Alembic 数据库迁移配置与迁移脚本 |
| `alembic/versions/` | 数据库迁移版本文件 (共 48 个迁移) |
| `scripts/` | 运维与工具脚本 |
| `tests/` | 后端单元测试 |

### 2.3 前端目录 (`frontend/`)

| 目录 | 功能 |
|------|------|
| `src/` | 前端源代码根目录 |
| `src/components/` | 可复用 React 组件 |
| `src/components/atelier/` | Atelier 设计主题相关组件 |
| `src/components/chapterAnalysis/` | 章节分析子组件 |
| `src/components/layout/` | 布局组件（AppShell、AuthGuard、ProjectProviderGuard） |
| `src/components/prompts/` | 提示词相关 UI 组件 |
| `src/components/ui/` | 通用 UI 基础组件（Toast、Confirm、Modal 等） |
| `src/components/writing/` | 写作台子组件（AI 生成抽屉、上下文预览等） |
| `src/contexts/` | React Context Provider（认证、项目等全局状态） |
| `src/hooks/` | 自定义 React Hook（数据获取、自动保存等） |
| `src/lib/` | 工具函数库（路由、拼音、动画、UI 文案等） |
| `src/pages/` | 页面级组件（每个路由对应一个 Page） |
| `src/services/` | 前端服务层（API 客户端、数据存储、SSE 等） |
| `public/` | 静态公共资源（favicon 等） |
| `scripts/` | 前端辅助脚本（如 UI 类检查脚本） |
