## 一、项目一句话介绍

**Atelier** 是一个面向 AI 辅助长篇小说创作的全栈 Web 平台。它整合 OpenAI / Anthropic / Gemini 等多种大语言模型，提供从项目规划、大纲生成、章节撰写、记忆管理到导出的一站式写作体验。核心亮点是**六层长期记忆系统**（故事记忆、结构化记忆、分形记忆、世界观百科、向量 RAG、知识图谱），能在长篇创作中持续将上下文注入 AI，保证前后连贯。

## 三、系统架构总览

```
浏览器 (React SPA)
   │
   ├── /api/* ──► Nginx 反代 ──► FastAPI (Uvicorn)
   │                                  │
   │                 ┌────────────────┤
   │                 │                │
   │            SQLAlchemy        httpx (异步)
   │                 │                │
   │           PostgreSQL      LLM 上游 API
   │           / SQLite       (OpenAI/Claude/Gemini)
   │                 │
   │            RQ Worker ◄── Redis
   │          (后台任务: RAG索引、批量生成、自动更新)
   │
   └── /* ──► 静态 SPA 资源
```

**后端五层分层**:

```
Routes  (api/routes/)     ← HTTP 入口，请求校验
   ↓
Schemas (schemas/)         ← Pydantic 数据验证
   ↓
Services (services/)       ← 业务逻辑核心（70+ 个服务）
   ↓
Models  (models/)          ← SQLAlchemy ORM（42 张表）
   ↓
Core/DB/LLM               ← 基础设施（配置、认证、数据库、LLM 适配）
```

## 六、核心数据流图解

### 6.1 章节 AI 生成（最核心流程）

```
用户点击「生成」
    │
    ▼
前端 AiGenerateDrawer ──收集参数──► POST /api/chapters/{id}/generate (SSE)
    │
    ▼ 后端
chapter_generation_app_service.py  ← 入口编排
    │
    ├── prepare_service    ← 收集大纲/角色/设置
    ├── plan_prepare       ← 构建生成计划
    ├── memory_service     ← 检索 9 种记忆:
    │     ├── story_memory        (故事记忆)
    │     ├── structured_memory   (实体/关系/事件/伏笔/证据)
    │     ├── worldbook           (关键词触发的世界观词条)
    │     ├── vector_rag          (向量语义检索)
    │     ├── graph_context       (知识图谱)
    │     ├── fractal_memory      (分形记忆)
    │     ├── chapter_context     (前文上下文窗口)
    │     ├── table_context       (自定义表格)
    │     └── glossary            (术语表)
    ├── context_optimizer  ← 压缩/裁剪上下文至预算内
    ├── prompt_service     ← 组装完整 prompt（模板 + 记忆 + 指令）
    ├── stream_service     ← 调用 LLM（含重试 + 流式回退）
    │     └── llm/client.py → providers/*.py → 上游 API
    └── post_process       ← 后处理（格式清理、长度校验）
    │
    ▼
SSE 流式返回 → 前端实时渲染 → 生成记录存储 (GenerationRun)
    │
    ▼（可选）
用户确认 → 触发记忆自动更新 → MemoryUpdateDrawer
```

### 6.2 记忆注入时序

```
生成请求到达
    │
    ▼
memory_retrieval_service.retrieve_memory_context_pack()
    │
    ├─[1] 故事记忆: 按章节号范围查询 story_memory 表
    ├─[2] 结构化记忆: 查询 structured_memory 表 (5 种 kind)
    ├─[3] 世界观百科: worldbook_service 关键词/正则/拼音匹配 + 递归扩展
    ├─[4] 向量 RAG: embedding → pgvector/ChromaDB 检索 → rerank → RRF 合并
    ├─[5] 知识图谱: graph_context_service 提取相关子图
    ├─[6] 分形记忆: 近期场景 + 中期弧度 + 长期索引检索
    ├─[7] 前文上下文: chapter_context_service 骨架/摘要/全文三层
    ├─[8] 表格上下文: table_context_service 相关表格数据
    └─[9] 术语表: glossary_service 相关术语
    │
    ▼
context_optimizer 按 token 预算压缩
    │
    ▼
注入 prompt → 发送 LLM
```
