# Plan: 条目系统 (Entry System)

## Goal
- 在项目工作台新增"条目"功能，位于"角色卡"和"搜索引擎"之间
- 条目结构：标题 + 标签 + 内容（纯粹简洁）
- 默认标签：设定、伏笔、情节；支持自定义标签
- 条目可注入到写作 AI 生成的提示词（记忆注入部分）

## Scope
- In:
  - 后端：Entry 数据库模型 + Alembic 迁移 + CRUD API
  - 前端：EntriesPage 页面 + 导航 + 路由 + API service
  - 集成：AI 生成 Drawer 中增加条目注入选项（全选/单选）
  - 后端：章节生成时将选中条目注入到提示词
- Out:
  - 不修改已有的 story_memory / structured_memory 系统
  - 不修改 vector RAG 系统
  - 不新增搜索索引集成（后续可做）

## Assumptions / Dependencies
- 沿用现有 Character/StoryMemory 的 CRUD 模式
- 前端沿用 CharactersPage 的 Drawer 编辑模式
- 标签以 JSON 数组存储（同 story_memory.tags_json 模式）
- Alembic 迁移使用项目已有的 SQLite 方式
- 条目注入作为新的 memory_module 添加到现有记忆注入系统

## 详细设计

### Entry 数据模型
```python
class Entry(Base):
    __tablename__ = "entries"
    id: str (PK, UUID)
    project_id: str (FK -> projects.id, CASCADE)
    title: str (max 255)
    content: str (Text)
    tags_json: str (Text, JSON array, default "[]")
    created_at: datetime
    updated_at: datetime
```

默认标签常量：
```python
DEFAULT_ENTRY_TAGS = ("设定", "伏笔", "情节")
```

### API 设计
- `GET /projects/{project_id}/entries` — 列表（分页，可按标签筛选）
- `POST /projects/{project_id}/entries` — 创建
- `PUT /entries/{entry_id}` — 更新
- `DELETE /entries/{entry_id}` — 删除

### 前端页面设计
- 顶部：搜索栏 + 标签筛选器 + "新增条目"按钮
- 主体：卡片网格（显示标题、标签 badges、内容预览）
- Drawer：标题输入、标签选择（默认三种 + 自定义输入）、内容编辑
- 自动保存（同 CharactersPage 模式）

### 记忆注入集成
- GenerateForm.context 新增 `entry_ids: string[]`
- AiGenerateDefaultSection 在"角色"选择下方新增"条目注入"区域
- 支持"全选"按钮 + 逐个勾选
- ChapterGenerateRequest.context 新增 `entry_ids` 字段
- 后端 prepare_service.py / prompt_service.py 中读取选中条目，格式化为 Markdown 注入到提示词
